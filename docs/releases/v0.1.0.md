# Index-Rebalancing v0.1.0

This release packages the exploratory UMass Amherst research project as a reproducible public artifact.

## Included

- A deterministic evaluator for the committed 92-row dataset.
- CI coverage across Python 3.11, 3.12, and 3.13.
- A documented legacy notebook environment.
- Dataset metrics, model-result caveats, and a cleaned full results table.
- Citation metadata, an MIT license, and a custom repository social preview.

## Scope

The release does not retrain the historical notebooks or claim a deployable trading strategy.
The research remains exploratory and is not investment advice.
